# QR Code Scanner

一个基于 Rust 的命令行二维码扫描工具，支持本地图片和 URL 解码。

## 功能特点

- 交互式输入，支持图片路径或 URL
- 多路径支持（逗号分隔）
- 自动识别并下载网络图片
- 内置多种图像增强算法提高识别率
- 彩色日志输出，带时间戳

## 快速开始

### 构建

```bash
cargo build
```

### 运行

```bash
cargo run
```

### 输入示例

```
请输入二维码图片的路径或 URL（多个用逗号分隔）:
C:\path\to\qrcode.png
```
