# QR Code Scanner

基于 Rust 的命令行二维码解码工具，支持本地图片与网络 URL 两种输入，内置多级图像预处理以提升识别率。

| 项目 | 说明 |
|------|------|
| 当前版本 | v1.0.0 |
| 目标平台 | Windows（其他平台可编译，控制台守卫为 Windows 专属） |
| 工具链 | Rust Edition 2024 |
| 程序类型 | 控制台应用（无图形界面） |
| 详细文档 | [docs/详细说明.md](docs/详细说明.md) |

## 功能特性

| 能力 | 说明 |
|------|------|
| 交互式输入 | 接受本地文件路径或 http / https URL |
| 批量处理 | 以英文逗号分隔多个输入，依次解码 |
| 自动下载 | 识别图片链接并下载到临时文件，结束后自动清理 |
| 智能增强 | 10 种图像预处理变体 + 4 种四角裁剪策略，逐级降级重试 |
| 分级日志 | INFO / WARNING / ERROR 彩色输出，精确到每个失败环节 |
| 双击可用 | 双击 exe 启动时，程序结束后由 PowerShell 接管窗口，不再闪退 |
| 单元测试 | 8 项测试覆盖 URL 判定、图像预处理与解码器，全部不依赖网络 |

## 环境要求

- Rust 工具链（Edition 2024）
- 网络连接（仅解码 URL 图片时需要）

## 构建与测试

```bash
# 调试构建
cargo build

# 发布构建，产物位于 target/release/
cargo build --release

# 运行单元测试
cargo test
```

## 运行

```bash
cargo run
```

也可直接双击 `target\release\QRCodeScanner.exe`。程序结束后会在同一窗口留下一个 PowerShell 提示符，解码输出不会随窗口消失。

> [!NOTE]
> **启动方式** — 输入只走标准输入，程序不解析命令行参数，因此将图片拖放到 exe 上不会触发解码。
> 背景与设计取舍见 [详细说明 · 启动方式与设计前提](docs/详细说明.md#启动方式与设计前提)。

## 输入格式

启动后出现提示符，输入一行文本：

```text
请输入二维码图片的路径或 URL（多个用逗号分隔）:
```

| 场景 | 输入示例 |
|------|----------|
| 单个本地图片 | `C:\path\to\qrcode.png` |
| 多个本地图片 | `C:\path\to\qr1.png, C:\path\to\qr2.jpg` |
| 网络图片 | `https://example.com/qrcode.png` |
| 带签名参数的 CDN URL | `https://s3.amazonaws.com/bucket/key.png?X-Amz-Signature=abc` |
| 本地与网络混合 | `C:\path\to\local.png, https://example.com/remote.jpg` |

## 支持的图片类型

PNG、JPG、JPEG、GIF、BMP、WEBP，扩展名大小写不敏感。

URL 同时兼容带端口（`:8080`）、查询参数（`?token=xxx`）与页内锚点（`#section`）等形式。

## 已知限制

- 不解析命令行参数，仅接受标准输入
- 无图形界面，仅控制台输出
- 逗号是批量输入的分隔符，路径本身不能包含英文逗号
