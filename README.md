# QR Code Scanner

一个基于 Rust 的命令行二维码扫描工具，支持本地图片和 URL 解码。

## 功能特点

- **交互式输入**：启动后提示输入图片路径或 URL
- **多路径支持**：可一次性输入多个路径，用逗号分隔
- **URL 支持**：自动识别并下载网络图片进行解码
- **图像预处理**：内置多种图像增强算法提高识别率
  - 灰度转换
  - 对比度增强
  - 二值化处理（多阈值）
  - 高斯模糊
  - 锐化处理
  - 颜色反转
  - 图像放大
- **裁剪解码**：对图像四角分别尝试解码
- **彩色日志**：带时间戳的彩色输出（INFO 蓝色、WARNING 黄色、ERROR 红色）

## 依赖项

- `bardecoder` - 二维码解码库
- `image` - 图像处理库
- `reqwest` - HTTP 客户端（用于下载 URL 图片）
- `regex` - 正则表达式（URL 验证）
- `tempfile` - 临时文件管理
- `chrono` - 时间戳
- `colored` - 终端彩色输出

## 构建

```bash
cargo build
```

## 使用方法

### 运行程序

```bash
cargo run
```

### 输入格式

程序启动后会提示输入：

```
请输入二维码图片的路径或 URL（多个用逗号分隔）:
```

#### 单个本地图片

```
C:\path\to\qrcode.png
```

#### 多个本地图片

```
C:\path\to\qrcode1.png, C:\path\to\qrcode2.jpg
```

#### URL 图片

```
https://example.com/qrcode.png
```

#### 混合输入

```
C:\path\to\local.png, https://example.com/remote.jpg
```

## 技术说明

### 图像预处理流程

1. 原始图像直接尝试解码
2. 转换为灰度图像
3. 增强对比度（2.0 倍）
4. 二值化处理（阈值 128、64、192）
5. 高斯模糊 + 二值化
6. 锐化处理
7. 颜色反转
8. 图像放大（2 倍）

### 裁剪策略

如果预处理后仍无法解码，会对图像四角分别裁剪尝试：
- 左上角
- 右上角
- 左下角
- 右下角

### URL 处理

- 自动识别 URL 格式（支持 png/jpg/jpeg/gif/bmp/webp）
- 使用临时文件存储下载的图片
- 解码完成后自动清理临时文件
- 设置 30 秒超时和浏览器 User-Agent

## 注意事项

- 确保二维码图像清晰完整
- 支持常见图片格式：PNG、JPG、JPEG、GIF、BMP、WEBP
- URL 图片需要网络连接
- 临时文件会自动清理，无需手动管理
